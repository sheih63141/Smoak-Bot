# 🌍 Куда посадить бота 24/7 — сравнение

Бот должен работать постоянно, иначе реакции на панели тикетов ничего не делают. Проект подготовлен под все три варианта сразу: `Dockerfile`, health-check на `/health`, самопинг от засыпания.

## Что уже встроено

- **`/health` → `200 ok`** — проверено, любой хостинг увидит сервис живым
- **Самопинг** — бот сам дёргает свой публичный адрес каждые 4 минуты и не даёт бесплатному инстансу уснуть. Подхватывает автоматически: `KOYEB_PUBLIC_DOMAIN`, `RENDER_EXTERNAL_URL`, `RAILWAY_PUBLIC_DOMAIN` или свой `PUBLIC_URL`
- **`MEMBERS_INTENT=0`** — стартует без галки в Developer Portal
- **Токен только в переменных окружения** — `.env` и `.dockerignore` настроены, в образ и в GitHub он не попадёт

## Сравнение

| | **Koyeb** | **Render** | **Railway** |
|---|---|---|---|
| Бесплатно | да, 1 веб-сервис (0.1 vCPU / 512 МБ) | да, 750 ч/мес | пробный кредит, дальше ~$5/мес |
| Засыпает | через 1 ч без трафика → лечим самопингом | через 15 мин → лечим самопингом | нет |
| Регион | Frankfurt | Frankfurt | EU West |
| Деплой | из GitHub **или** папки через CLI | только из GitHub | из GitHub или образа |
| Что нужно от вас | аккаунт (вход через GitHub) | аккаунт GitHub + Render | аккаунт + карта для постоянства |
| Готовый конфиг | `koyeb.yaml` | `render.yaml` | `railway.json` |

**Вывод:** Koyeb дешевле по усилиям — умеет деплой прямо из папки, GitHub не обязателен. Render удобнее, если репозиторий на GitHub уже есть: там `render.yaml` разворачивается одной кнопкой Blueprint.

## Что мне нужно, чтобы сделать деплой за вас

Создать аккаунт я не могу — там ваша почта и подтверждение. Но после регистрации всё остальное сделаю сам, нужен только токен:

| Хостинг | Что прислать | Где взять |
|---|---|---|
| **Koyeb** | API-токен | app.koyeb.com → Account → API → Create API token |
| **Render** | API-ключ + ссылка на репозиторий GitHub | dashboard.render.com → Account Settings → API Keys |
| **Railway** | Project token | railway.app → Account → Tokens |

После деплоя токен отзовите — он больше не нужен.

## Если хостинг не нужен вообще

`start.bat` (Windows) или `start.sh` (Linux/macOS) — бот работает, пока включён компьютер. Для сервера на 50–500 человек этого мало: компьютер выключился — тикеты умерли.
