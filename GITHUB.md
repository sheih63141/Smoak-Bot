# 🐙 Через GitHub — бот 24/7 без хостинга

Два варианта. Первый — **бот живёт прямо в GitHub Actions**: бесплатно, без карт, без хостингов, без вашего компьютера. Второй — репозиторий на GitHub, а работать бот будет на Koyeb/Render (надёжнее, но нужен аккаунт у них).

Оба начинаются одинаково: код должен попасть на GitHub.

---

## Автомат: всё делает скрипт (`deploy_github.py`)

Если дадите GitHub-токен, репозиторий, пуш, секрет и запуск сделает скрипт:

```bash
GH_TOKEN=ghp_ваш_токен DISCORD_TOKEN=токен_бота python3 deploy_github.py
```

Что он делает по шагам:
1. проверяет токен и узнаёт ваш ник
2. создаёт репозиторий `smoak-bot` (публичный — безлимит минут Actions)
3. заливает код в ветку `main`
4. шифрует токен бота и кладёт его в секреты Actions (`DISCORD_TOKEN`)
5. запускает workflow
6. ждёт завершения и показывает ссылки на логи

Токен нужен classic с галочками **repo** и **workflow**:
github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token.

Проверено до авторизации: при неверном токене скрипт честно пишет `401 Bad credentials`.

## Часть 1. Репозиторий на GitHub (вручную, 3 минуты)

### Вариант через сайт (без консоли)

1. **github.com/new** → Repository name: `smoak-bot` → **Public** или **Private** (для Actions лучше **Public**, минуты не тратятся) → Create repository
2. На открывшейся странице — ссылка **uploading an existing file**
3. Перетащите **всё содержимое папки `discord-server`**, включая скрытую папку `.github`

   > ⚠️ Файл `.env` не загружайте — в нём токен. Он в `.gitignore`, GitHub его и так не примет через git, но при перетаскивании мышкой проверьте.

4. Commit changes

### Вариант через консоль

```bash
cd discord-server
git remote add origin https://github.com/ВАШ_НИК/smoak-bot.git
git branch -M main
git push -u origin main
```

---

## Часть 2. Токен бота в секреты

1. Репозиторий → **Settings** → **Secrets and variables** → **Actions**
2. **New repository secret**
3. Name: `DISCORD_TOKEN` · Secret: ваш токен из Developer Portal → Bot
4. **Add secret**

Токен хранится в секретах GitHub и в коде не появляется — можно спокойно делать репозиторий публичным.

---

## Часть 3. Запуск

1. Вкладка **Actions** → в списке слева выберите **SmoakTeam bot**
2. Если GitHub спросит — нажмите **I understand my workflows, go ahead and enable them**
3. Кнопка **Run workflow** → **Run workflow**
4. Через 40–60 секунд откройте запуск → шаг **Запускаю бота**. Там должно быть:

```
Бот на связи: Bot  Smoak#6527
  сервер: SmoakTeam (1568607492991353053) | участников 13
[ticket] панель готова: 🎫 📋 📝
[heartbeat] 03:15:00 — бот жив, соединение: ок
```

Всё — бот работает. Нажмите 🎫 на панели: тикет откроется.

## Как это держится 24/7

GitHub даёт максимум **6 часов** на один запуск. Схема обхода встроена в workflow:

- бот работает 5 ч 56 мин, затем корректно выходит сам (`timeout 21400`)
- расписание `*/30 * * * *` каждые 30 минут проверяет, свободен ли слот, и поднимает бота заново
- `concurrency` не даёт запускам убивать друг друга — второй ждёт в очереди

Итог: непрерывная работа с короткими перерывами на пересборку контейнера (обычно меньше минуты).

**Честные ограничения GitHub Actions:**

| Что | Как это выглядит |
|---|---|
| Лимит 6 ч на запуск | обходится расписанием, короткие паузы возможны |
| Расписание может задержаться на 5–15 мин | тикет, открытый в момент паузы, не обработается — кликните ещё раз |
| Минуты | публичный репозиторий — безлимит, приватный — 2000 мин/мес (хватает: один постоянный запуск) |
| Правила GitHub | длительные процессы в Actions — серая зона, GitHub вправе притормозить. Для клуба лучше перейти на Koyeb |

## Часть 4 (по желанию). Тот же репозиторий на настоящем хостинге

Когда GitHub-репозиторий есть, подключить нормальный хостинг — 2 минуты:

**Render:** dashboard.render.com → **New** → **Blueprint** → выбрать репозиторий → Render сам прочитает `render.yaml` → вписать `DISCORD_TOKEN` → Apply.

**Koyeb:** см. `KOYEB.md` или запустить `./deploy-koyeb.sh` — файлы `Dockerfile`, `koyeb.yaml` в репозитории уже готовы.

Там бот работает по-настоящему непрерывно, без лимита в 6 часов.

## Если что-то не так

| Симптом | Причина |
|---|---|
| `❌ ВКЛЮЧИТЕ ОДНУ ГАЛКУ` | в секретах `MEMBERS_INTENT=1`, а галки в портале нет — поставьте `0` |
| Actions не запускается по расписанию | в публичном репозитории должен быть хоть один коммит за 60 дней; или отключите Actions → Enable |
| Бот отработал 6 ч и умер | так и задумано: следующий запуск поднимет его в течение 30 минут |
| Тикет не создаётся | проверьте, что запуск активен (Actions → жёлтый кружок), а не зелёная галочка |
