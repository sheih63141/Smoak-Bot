# 🎮 Discord-сервер: общение, игры, стримы

Готовый комплект для сервера на 50–500 человек: структура каналов, роли, матрица прав, тексты, регламент модерации и скрипт, который собирает всё это автоматически.

**Я не могу создать сервер в вашем аккаунте** (нет доступа к Discord). Поэтому три шага за вами, они занимают ~15 минут:

1. Создать сервер: Discord → **+** → «Создать свой сервер» → название → иконка.
2. Создать бота: [discord.com/developers/applications](https://discord.com/developers/applications) → **New Application** → вкладка **Bot** → **Reset Token** → скопировать токен → пригласить бота на сервер через OAuth2 URL Generator (scopes: `bot` + `applications.commands`, права: `Administrator`).
3. Запустить скрипт:
   ```bash
   cd discord-server
   pip install -r requirements.txt
   cp .env.example .env      # вставить токен и ID сервера
   python setup_bot.py --dry-run   # посмотреть план
   python setup_bot.py             # создать всё
   ```

Посмотреть план, вообще не трогая Discord: `python setup_bot.py --dry-run` (работает и без токена).
Откатить всё, что создал скрипт: `python setup_bot.py --wipe` (сначала прогоните с `--dry-run --wipe`).

## 1. Структура сервера

```
📌 СТАРТ
 ├ #правила            только чтение — правила + ✅ для подтверждения
 └ #выбери-роли        только чтение — реакции на игры и уведомления

💬 ОБЩЕНИЕ
 ├ #общий-чат          главный чат
 ├ #мемы-и-арты        мемы, скриншоты, творчество
 ├ #клипы              лучшие моменты
 └ #помощь             вопросы, медленный режим 5 сек

🎮 ИГРЫ
 ├ #поиск-игроков      «игра / сколько нужно / войс»
 ├ #игровые-новости    патчи, релизы, скидки
 └ #предложить-игру    идеи ивентов и турниров

🎥 СТРИМЫ
 ├ #анонсы-стримов     пишут стримеры и модераторы
 └ #стрим-обсуждение   обсуждение эфиров

🔊 ГОЛОСОВЫЕ
 ├ 🔊 Общий
 ├ 🎮 Игровая 1 (6)
 ├ 🎮 Игровая 2 (6)
 ├ 🎮 Игровая 3 (5)
 ├ 🎧 Стрим-комната (10)
 └ 🎉 Ивент (20)

🎫 ПОДДЕРЖКА
 └ #создать-тикет      кнопка → приватный канал с командой

🛠 КОМАНДА (скрыто от всех)
 ├ #мод-чат            только модераторы и админы
 ├ #логи              логи наказаний (пишет Carl-bot)
 └ #заявки            заявки в команду

💤 AFK
 └ AFK
```

Почему так: 24 канала на 50–500 человек — комфортный объём. Меньше — всё в одном флуде, больше — люди теряются. Голосовые каналы с лимитами не дают «забить» все комнаты одной компанией.

## 2. Роли (сверху вниз)

| # | Роль | Цвет | Что может |
|---|---|---|---|
| 1 | 👑 Владелец | золотой | всё (администратор) |
| 2 | 🛡 Администратор | красный | всё; назначает команду |
| 3 | 🔨 Модератор | оранжевый | мут/тайм-аут, кик, удаление сообщений, перемещение по войсам, аудит-лог |
| 4 | 🧰 Хелпер | синий | удаление сообщений, тайм-аут, помощь в тикетах. **Без** кика и бана |
| 5 | 🎥 Стример | розовый | приоритет в войсе, анонсы стримов, вложения |
| 6 | 🤖 Бот | серый | только для ботов |
| 7 | ⭐ Активный | зелёный | косметика за активность (выдаётся вручную или ботом за уровень) |
| 8 | 👋 Участник | фиолетовый | базовая роль после верификации |
| 9 | 🔇 Заглушённый | тёмный | запрет писать и говорить — роль для мута без тайм-аута |

**Роли самоассайна** (без прав, только пинги): 🎮 CS2, 🎮 Dota 2, ⛏ Minecraft, 🚗 GTA, 🔫 Valorant, 🎲 Настолки, 🔔 Анонсы, 🎥 Стримы, 🎉 Ивенты. Платформенных ролей (PC / PlayStation / Xbox) на сервере нет.

Ключевые принципы:
- **Баны — только у администрации.** Это главная защита от «ударил по ошибке и забанил полсервера».
- Хелпер — это «выпускник» участника: может прибраться в чате, но не может выгнать.
- 🔇 Заглушённый стоит **ниже** всех: его `deny` перебивается только правами канала.

## 4. Онбординг новичка (3 клика)

1. Заходит по инвайту → видит Стартовую категорию и голосовые, остальное доступно, но «правила» сверху.
2. Читает #правила → ставит ✅ (это подтверждение согласия; включите в настройках сервера **Правила сервера** и требование принять их).
3. Идёт в #выбери-роли → ставит 2–3 реакции → получает пинги по интересам и больше не пропускает сборы.

Тексты приветствия и онбординга — в `texts/welcome.md`.

Настройки сервера для этого экрана:
- **Настройки сервера → Приветствие**: канал `#правила`, текст приветствия, «Отправлять в личку» выключить.
- **Настройки сервера → Модерация → Уровень верификации: Средний** (аккаунт должен быть старше 5 минут — режет рейд-ботов).
- **Настройки сервера → Модерация → AutoMod**: включить все 4 пресета + `/` «Блокировать упоминание @everyone».

## 5.5. Автоматика: мут, мут-зона, авто-AFK (`automod_bot.py`)

Один файл, который надо держать запущенным постоянно (свой ПК, VPS, хостинг ботов):

```bash
export DISCORD_TOKEN=...   # или .env
export GUILD_ID=...
export IDLE_MINUTES=15         # через сколько минут неактивности кидать в AFK
export MUTE_TIMEOUT_MINUTES=60 # тайм-аут, если роль мута выдали вручную
python automod_bot.py
```

Что делает:

| Событие | Реакция |
|---|---|
| Участнику выдали тайм-аут (timeout) | бот выдаёт роль 🔇 Заглушённый, пишет в #логи |
| Тайм-аут снят | роль снимается |
| Роль 🔇 Заглушённый выдали вручную | бот ставит тайм-аут на 60 мин (чтобы мут работал и в голосе) |
| Заглушённый зашёл в любой войс | переносится в 🤐 Мут-зону |
| Сидит в войсе и N минут молчит (не говорит, не стримит, не писал в чат) | переносится в AFK |

Не трогает команду и стримеров (список `SKIP_ROLES`), не трогает тех, кто стримит или включил камеру.

**Требование:** в Developer Portal → Bot → Privileged Gateway Intents включить **SERVER MEMBERS INTENT**. Без этой галки бот не запустится — Discord не отдаёт список участников и тайм-ауты.

Пока процесс не запущен, работает только родной AFK-таймаут Discord (Настройки сервера → AFK-канал, 5 мин) — он уводит в AFK тех, кто отключился, но не тех, кто «висит» в войсе молча.

## 5.6. Автоуведомления о стриме (`twitch_notify.py`)

Канал Twitch: **twitch.tv/smoak52** → посты в **#анонсы-стримов**.

```
раз в 60 сек спрашивает Twitch о статусе эфира
начался эфир  → пост: название стрима, игра, зрители, время начала, превью, ссылка (+ закреп)
эфир идёт     → раз в 5 минут обновляет счётчик зрителей в том же сообщении
эфир кончился → правит сообщение: «Эфир закончился» + длительность
```

Twitch-ключи не нужны — используется публичный GraphQL веб-плеера (проверено: канал `smoak52` находится, поля «название/игра/зрители/начало» отдаются).

```bash
pip install -r requirements.txt     # discord.py + aiohttp
export DISCORD_TOKEN=...  GUILD_ID=...
export TWITCH_LOGIN=smoak52
export STREAM_CHANNEL=анонсы-стримов   # куда постить
export POLL_SECONDS=60                 # период опроса
export PING_ROLE=                      # имя роли, если нужен пинг (по умолчанию без пинга)
python twitch_notify.py
```

Работает **без** Server Members Intent — можно запускать прямо сейчас, отдельно от автоматики модерации. Если нужен один процесс на всё: `automod_bot.py` сам подхватывает этот модуль и публикует уведомления вместе с модерацией.

Состояние (был ли эфир, id сообщения для правок) хранится в `twitch_state.json` — после перезапуска бот не задублирует анонс. Проверка без реального стрима: `TWITCH_FAKE_LIVE=1 python twitch_notify.py`.

## 5.7. Вход на сервер: правила + роль (`onboarding_setup.py`, `join_gate.py`)

Что видит новичок, заходя по инвайту:

```
экран «Правила сервера» (Discord «Сообщество»)
   [x] Я прочитал(а) правила и согласен(на) с ними
   [x] Мне 13 лет или больше
        ↓ «Принять правила»
онбординг:
   • Подтверди участие → «👋 Я участник — с правилами ознакомлен» (обязательный, выдаёт роль)
   • Что тебе интересно? → 🎮 Игры / 🎥 Стримы / 💬 Общение (необязательный)
        ↓
роль 👋 Участник + доступ к каналам
```

Пока правила не приняты, каналы сервера новичку недоступны — это делает сам Discord, бот не нужен.

- `onboarding_setup.py` — одноразовая (и повторяемая) настройка: включает Community, назначает `#правила` каналом правил, `#игровые-новости` — каналом обновлений, создаёт экран с галочками и онбординг-опросы с ролью.
- `join_gate.py` — страховка: если человек прошёл правила, но роль не выдалась (или онбординг отключили), бот выдаёт `👋 Участник` в момент принятия правил и пишет вход в `#логи`. Требует Server Members Intent.

Кнопки и текст правил — в `texts/welcome.md`.

## 5.8. Закрытый сервер: два канала на входе

Новичок без роли видит **ровно два канала**:

```
📌 СТАРТ
  #правила        правила, закреплены сверху, писать нельзя
  #получить-роль   кнопка «✅ Я прочитал правила — выдать роль»
```

Всё остальное (чат, игры, стримы, голосовые, тикеты, AFK) скрыто за ролью `👋 Участник`.

Как это устроено:

| Механизм | Что делает |
|---|---|
| Права категорий | у `@everyone` запрет «Просмотр каналов» на всех категориях, кроме `📌 СТАРТ`; у `👋 Участник`, `⭐ Активный`, `💎 ВИП` — разрешение |
| `role_gate.py` | кнопка в `#получить-роль`: нажал → роль выдана → каналы открылись, `#получить-роль` исчезает (у роли участника стоит запрет на просмотр) |
| `join_gate.py` | страховка: выдаёт роль в момент входа/принятия правил, если кнопку пропустили |
| Онбординг Discord | **выключен** — убрал «Каналы и роли» из списка, выбор роли теперь только кнопкой |
| Экран правил Discord | **выключен** — он не скрывает каналы, поэтому гейт держится на правах |

Проверка: зайдите с второго аккаунта — должны видеть только `#правила` и `#получить-роль`, после кнопки открывается всё.

**Тикеты без сторонних ботов:** `ticket_gate.py` публикует в `#создать-тикет` панель с кнопкой «🎫 Создать тикет» → создаёт приватный канал в `🎫 ТИКЕТЫ` (видят автор + `🧰 Хелпер`, `🔨 Модератор`, `🛡 Администратор`), кнопка «🔒 Закрыть тикет» сохраняет транскрипт `.txt` в `#логи` и удаляет канал. Один открытый тикет на человека. Если настроите панель Ticket Tool — уберите `ticket_gate` из `automod_bot.py`, чтобы не было двух систем.

## 6. Регламент модерации

| Нарушение | Первое | Второе | Третье |
|---|---|---|---|
| Спам, флуд, капс | предупреждение | мут 1 ч | мут 24 ч |
| Реклама без разрешения | удалить + предупреждение | мут 24 ч | бан |
| Хамство, конфликт | предупреждение в тикете | мут 24 ч | мут 7 дней |
| NSFW, шок-контент, 18+ | мут 7 дней | бан | — |
| Травля, угрозы, дискриминация | **бан сразу** | — | — |
| Читы, обход бана | **бан сразу** | — | — |

Правила для команды:
- Наказание всегда фиксируется в #логи (Carl-bot пишет сам) и объясняется человеку в личку или в тикете.
- Модератор не решает конфликт, в котором участвует сам — передаёт другому.
- Спорные баны обсуждаются в #мод-чат, а не в общем чате.
- Апелляции — только через #создать-тикет, разбирает администратор.

## 7. Как раскачать сервер (50 → 500)

**Первые 50 человек.** Личные приглашения 10–15 знакомых, тематические чаты по играм, ваш стрим с приглашением в описании. Цель — «живой» общий чат: пока в нём 5 сообщений в день, остальные каналы не нужны.

**50–200.** Вводите ритм: «Игровой вечер» в четверг и «Стрим-сейшн» в субботу. Анонс за день, потом пинг роли 🎉 Ивенты. Собирайте голосовые — именно они держат людей, а не текст. Появляются первые хелперы из активных.

**200–500.** Нужны: тикеты (уже есть), чёткая команда 3–5 человек, автомод в жёстком режиме, отдельный закрытый канал для команды. Появляется смысл в ролях «⭐ Активный» и в турнирах/ивентах с призами. Инвайты — с ограничением по времени, чтобы не пришли рейд-боты.

Что убивает серверы: пустой общий чат, «мёртвые» каналы-дубли, отсутствие ивентов, админ-самодур и модераторы, которые молчат в чате.

## 9. Если что-то пошло не так

| Симптом | Причина и решение |
|---|---|
| `❌ Нет DISCORD_TOKEN` | Нет `.env` или в нём пустой токен. `cp .env.example .env` |
| `❌ Токен не принят` | Токен перевыпущен/скопирован не полностью → Reset Token заново |
| Бот на сервере, но ничего не создаёт | В `GUILD_ID` чужой сервер, или у бота нет прав «Администратор» |
| `⚠️ не удалось переставить роли` | У бота роль ниже нужной. Перетащите роль бота в самый верх списка руками |
| Роли создались не в том порядке | Перетащите вручную: Настройки сервера → Роли. Порядок = иерархия |
| Хочу другие каналы | Правится в `setup_bot.py` в списках `ROLES` и `CATEGORIES`, затем повторный запуск — лишнее не дублируется |
| Нужно всё пересобрать | `python setup_bot.py --wipe --dry-run`, потом `--wipe` |
