## Шаг 1. Реакция ✅ → роль 👋 Участник (2 минуты)

1. Откройте [carl.gg](https://carl.gg) → **Login with Discord** → выберите **SmoakTeam**.
2. В левом меню → **Reaction Roles** → кнопка **New Reaction Role** (или `+`).
3. Заполните:

| Поле | Значение |
|---|---|
| Channel | `#правила` |
| Message | **Any Message** (если просит ID — вставьте `1568626359683780690`) |
| Emoji | `✅` |
| Roles | `👋 Участник` |
| Type / Mode | **Normal** (не Unique, не Verify) |
| Remove role on unreact | **выключено** — чтобы роль не слетала, если человек случайно снял реакцию |

4. **Save / Create**.

Готово. Теперь любой, кто ставит ✅ под правилами, мгновенно получает `👋 Участник`, а вместе с ним и весь сервер. Ваш компьютер и мой бот для этого не нужны вообще.

**Проверка:** зайдите с другого аккаунта (или попросите друга) — поставить ✅, роль должна появиться в течение пары секунд.

### Если хотите вторую точку входа
То же самое сделайте для канала `#получить-роль` (Message ID `1568650244483317812`). Тогда работают обе реакции: и под правилами, и в канале получения роли.

### Важно про порядок ролей
Роль Carl-bot должна стоять **выше** `👋 Участник` в списке ролей — у вас она уже поднята на 8-ю позицию, а `👋 Участник` на 1-ю, так что всё в порядке. Если когда-нибудь перетащите — не опускайте Carl-bot ниже.

## Шаг 2. Тикеты — Ticket Tool (5 минут)

Carl-bot тикетов не делает, для этого второй бот, который у вас уже стоит.

1. Откройте [tickettool.xyz](https://tickettool.xyz) → **Login with Discord** → **SmoakTeam**.
2. **Panels** → **New Panel**.

**Панель «Вопрос»:**

| Поле | Значение |
|---|---|
| Panel channel | `#создать-тикет` |
| Panel title | `Поддержка` |
| Button label | `Задать вопрос` |
| Button color | Blurple (синий) |
| Ticket category | `🎫 ТИКЕТЫ` |
| Support roles | `🧰 Хелпер`, `🔨 Модератор`, `🛡 Администратор` |
| Transcripts | включить → `#логи` |

**Панель «Заявка»** (вторая, в том же канале):

| Поле | Значение |
|---|---|
| Button label | `Заявка в команду` |
| Button color | Gray (серый) |
| Ticket category | `📋 ЗАЯВКИ` |
| Support roles | **только** `🔨 Модератор`, `🛡 Администратор` |
| Transcripts | включить → `#логи` |

Ключевой момент: у панели «Заявка» в support roles **не должно быть хелпера** — тогда заявки на модерацию/хелпера он не увидит, а вопросы увидит. Ровно то, что вы просили.

3. **Save** — панель появится в `#создать-тикет` с кнопками.
