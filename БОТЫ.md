# Боты для SmoakTeam: кого добавить и что настроить

## Чего я сделать не могу

Добавить бота на сервер может **только человек** — на экране авторизации Discord нужно нажать «Авторизовать» под своим аккаунтом, а панели ботов (Carl-bot, Ticket Tool) вообще требуют входа через ваш Discord. Токен моего бота такого права не даёт.

Что я уже сделал за вас: подготовил каналы и права, посчитал точные ссылки приглашения с нужным набором прав (без «Администратора», чтобы боты не могли больше, чем нужно) и создал категорию `🎫 ТИКЕТЫ` для тикетов и архива. Вам остаётся три клика по ссылке и настройка в панели.

## Кого добавить: 3 бота (не больше)

### 1. Carl-bot — логи, автомод, приветствие
Приглашение (права проверены):
```
https://discord.com/oauth2/authorize?client_id=235148962103951360&permissions=1426898545878&scope=bot%20applications.commands
```
Что настроить в панели [carl.gg](https://carl.gg):
- **Logging → Mod log** → `#логи` (баны, кики, тайм-ауты, удалённые и изменённые сообщения)
- **Logging → Message log** → включить (кто что удалил — видно, даже если модератор не заметил)
- **Automod → Softban/Caps/Links/Invites** → `#логи`, действие «delete + warn»
- **Welcome** → канал `#правила`, текст из `texts/welcome.md`
- **Autorole** → роль `👋 Участник` новичкам (после верификации)
- **Reaction roles** → в `#выбери-роли`, если решите вернуть роли по интересам

Зачем, если у нас свой бот: Discord-логи и автомод у Carl-bot живут 24/7 на его серверах, а мой бот работает только пока запущен у вас. Логи — та вещь, которую нельзя терять.

### 2. Ticket Tool — тикеты
```
https://discord.com/oauth2/authorize?client_id=557628352828014614&permissions=395405814864&scope=bot%20applications.commands
```
Настройка на [tickettool.xyz](https://tickettool.xyz):
- **Panels → New Panel** → канал `#создать-тикет`, кнопка «Создать тикет»
- **Ticket category** → `🎫 ТИКЕТЫ` (я её уже создал, скрыта от всех)
- **Support roles** → `🔨 Модератор`, `🧰 Хелпер`
- **Transcripts** → включить, канал `#логи` (или `#заявки`)
- Тема тикета → обязательно, максимум 1 открытый тикет на человека

### 3. Statbot — счётчики участников
```
https://discord.com/oauth2/authorize?client_id=491769129318088714&permissions=85008&scope=bot%20applications.commands
```
Настройка: [statbot.net](https://statbot.net) → **Counters** → каналы вида `Участников: 8`, `Онлайн: 3` внизу списка каналов. Даёт эффект «живого» сервера, особенно когда вас немного.

## Кого НЕ надо добавлять

| Бот | Почему нет |
|---|---|
| **Музыкальные** (Rythm-подобные) | Discord выпилил музыку из голосовых у большинства ботов, работают криво и требуют лишних прав |
| **Verify-боты** (Wick, Double Counter) | У вас уже уровень верификации «Средний» + фильтр контента + AutoMod — рейд-боты не пройдут |
| **Level-боты** (MEE6/ProBot уровни) | При 8 участниках смысла нет; вернуть, когда будет 100+ человек |
| **Streamcord / стрим-уведомления** | Уже есть свой `twitch_notify.py`, работает точнее и без лишних прав |
| **Модерация отдельно** (Wick и др.) | Дублирует мой бот + Carl-bot, три системы модерации будут конфликтовать |

Итого на сервере: **мой бот** (мут-автоматика + стрим-анонсы) + **Carl-bot** + **Ticket Tool** + **Statbot** = 4 бота. Это нормальный предел для 50–500 человек.

## Порядок действий

1. Перейдите по ссылке Carl-bot → выберите SmoakTeam → «Авторизовать» (права уже выверены).
2. Зайдите на carl.gg → Logging → укажите `#логи`. Это обязательный минимум.
3. Ссылка Ticket Tool → авторизация → панель в `#создать-тикет`.
4. Ссылка Statbot → авторизация → счётчики (по желанию).
5. Перетащите роли ботов **под** роль `Bot Smoak` — чтобы иерархия не сломалась.

После этого скиньте мне вывод «кто добавлен» — проверю, что у ботов хватает прав, а у `@everyone` не появилось лишнего.
