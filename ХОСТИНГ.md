# Как поднять бота, чтобы всё работало 24/7

## Почему сейчас «ничего не работает»

Кнопки и реакции обрабатывает **бот**. Пока его процесс не запущен, происходит вот что:

- реакция ✅ в правилах ничего не выдаёт → новичок сидит с двумя каналами и без роли;
- реакция 🎫 на панели ничего не создаёт → тикетов нет, а значит и хелперам нечего смотреть;
- в интерфейсе Discord появляется «Приложение не ответило вовремя».

Я держал бота в своей песочнице, но она живёт только внутри моего ответа: между сообщениями процесс замирает, websocket-соединение с Discord рвётся, и все реакции перестают доходить. В логе это видно буквально: за всё время пришли только реакции **самого бота**, ни одной от живого человека.

**Права на сервере при этом настроены правильно** (проверено):

| Что | Кто видит |
|---|---|
| `#создать-тикет` | все роли + участники |
| `🎫 ТИКЕТЫ` (вопросы) | 🧰 Хелпер, 🔨 Модератор, 🛡 Админ |
| `📋 ЗАЯВКИ` | 🔨 Модератор, 🛡 Админ — хелперу запрещено |
| `#получить-роль` | все, у кого нет роли участника |

То есть как только появится работающий бот — тикеты и заявки заработают сразу, ничего доделывать не нужно.

## Вариант 1. Свой бот на ПК (быстрее всего, но ПК должен быть включён)

**Windows:**
1. Установить Python 3.11+ (python.org, галочка «Add Python to PATH»).
2. В папке `discord-server`: `pip install -r requirements.txt`
3. Создать файл `.env` рядом с `automod_bot.py`:
   ```
   DISCORD_TOKEN=твой_токен
   GUILD_ID=1568607492991353053
   MEMBERS_INTENT=1
   IDLE_MINUTES=15
   ```
4. Запуск: двойной клик по `start.bat` (создайте его с текстом ниже) или в терминале `python automod_bot.py`.
   ```bat
   @echo off
   cd /d %~dp0
   python -u automod_bot.py
   pause
   ```
5. В Developer Portal → Bot → **Privileged Gateway Intents → Server Members Intent → Save**. Это нужно, чтобы работали авто-AFK, синхронизация мута и выдача роли по входу.

**Linux/macOS:** то же самое, `python3 automod_bot.py`.

Минус: выключаете компьютер — бот умирает.

## Вариант 2. VPS (правильный способ, ~10 минут)

Любой хостинг за 150–300 ₽/мес (Timeweb, Aeza, Hetzner), Ubuntu 22.04+.

```bash
sudo apt update && sudo apt install -y python3 python3-pip git
sudo mkdir -p /opt/discord-server && cd /opt/discord-server
# скопировать сюда файлы из папки discord-server (scp / git / wget)
sudo pip3 install -r requirements.txt

# автозапуск через systemd
sudo cp smoak-bot.service /etc/systemd/system/
sudo nano /etc/systemd/system/smoak-bot.service   # вписать DISCORD_TOKEN
sudo systemctl daemon-reload
sudo systemctl enable --now smoak-bot
sudo journalctl -u smoak-bot -f                   # логи в реальном времени
```

Бот перезапускается сам после падения и после перезагрузки сервера (`Restart=always`).

## Вариант 3. Бесплатный облачный хостинг (Railway / Render / Fly.io)

В папке уже лежат `Dockerfile` и `Procfile` — деплой в один клик:

1. Зарегистрироваться на [railway.app](https://railway.app) (вход через GitHub).
2. New Project → Deploy from repo (залить папку в свой GitHub-репозиторий) **или** `railway up` из папки.
3. Variables:
   ```
   DISCORD_TOKEN=...
   GUILD_ID=1568607492991353053
   MEMBERS_INTENT=1
   ```
4. Deploy. Railway сам поднимет контейнер и будет перезапускать его при падении.

Бесплатный тариф Railway даёт ограниченные часы — для одного бота обычно хватает.

## Вариант 4. Вообще без своего бота (не нужен хостинг)

Отдаём обе задачи ботам, которые уже работают на чужих серверах:

**Роль по реакции — Carl-bot** (2 минуты):
1. [carl.gg](https://carl.gg) → выбрать SmoakTeam → **Reaction Roles** → **New**.
2. Channel: `#правила`, Message: сообщение с правилами (или «Any message»).
3. Emoji: `✅` → Role: `👋 Участник` → **Create**.
4. Готово: реакция выдаёт роль всегда, без вашего компьютера.

**Тикеты — Ticket Tool** (5 минут):
1. [tickettool.xyz](https://tickettool.xyz) → ваш сервер → **Panels → New Panel**.
2. Панель 1 «Вопрос»: канал `#создать-тикет`, кнопка `Задать вопрос`,
   category `🎫 ТИКЕТЫ`, support roles: `🧰 Хелпер`, `🔨 Модератор`, `🛡 Администратор`.
3. Панель 2 «Заявка»: канал `#создать-тикет`, кнопка `Заявка в команду`,
   category `📋 ЗАЯВКИ`, support roles: только `🔨 Модератор`, `🛡 Администратор`.
   (Хелпер заявок не увидит — так и задумано.)
4. Transcripts → канал `#логи`.

Минус: авто-AFK, синхронизация мута и анонсы стримов остаются только у своего бота.

## Что выбрать

| Ситуация | Решение |
|---|---|
| Есть включённый ПК и не хочется платить | Вариант 1 |
| Нужно «поставил и забыл» | Вариант 2 (VPS) или 3 (Railway) |
| Не хочется вообще возиться с хостингом | Вариант 4 (Carl-bot + Ticket Tool) |
| Хочется всё своё, включая стрим-анонсы и авто-AFK | Варианты 1–3, причём с Server Members Intent |

## Диагностика

В логе бота должно быть видно:

```
[heartbeat] 16:02:11 — бот жив, соединение: ок
[reaction] ✅ в канале 1568645377844969677 от 970550805277081601
[role_gate] ✅ добавлена в #получить-роль
[ticket] создан вопрос-smoak52 (вопрос) по реакции 🎫
```

- **Нет `[heartbeat]`** — процесс не запущен или упал.
- **Есть heartbeat, но нет `[reaction]` при клике** — соединение с Discord мертво, перезапустите.
- **`[reaction]` есть, а роль не выдаётся** — роль бота ниже `👋 Участник` или не включён Server Members Intent.
